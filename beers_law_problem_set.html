Beer's Law / Spectroscopy Problem Set (5 Questions)

Instructions:

Use Beer's Law, A = ε × l × c, to solve the following problems. Assume the path length (l) is 1.00 cm unless specified otherwise.

Problems:

  1. The molar absorptivity (ε) of a compound is 1500 L·mol⁻¹·cm⁻¹. What is the absorbance of a 2.0 × 10⁻⁴ M solution in a 1.00 cm cuvette?
  2. A solution has an absorbance of 0.450 at 500 nm. If ε = 900 L·mol⁻¹·cm⁻¹ and the path length is 1.00 cm, what is the concentration of the solution?
  3. What is the concentration of a solution if the absorbance is 0.680, ε = 1.25 × 10³ L·mol⁻¹·cm⁻¹, and the path length is 2.00 cm?
  4. If a solution with concentration 5.0 × 10⁻⁵ M shows an absorbance of 0.150 in a 1.00 cm pathlength cuvette, what is the molar absorptivity?
  5. A cuvette of 2.00 cm pathlength contains a solution with ε = 2.50 × 10³ L·mol⁻¹·cm⁻¹ and concentration 3.0 × 10⁻⁴ M. Calculate the absorbance.

Answer Key

  1. A = 0.30
  2. c = 5.0 × 10⁻⁴ M
  3. c = 2.72 × 10⁻⁴ M
  4. ε = 3.0 × 10³ L·mol⁻¹·cm⁻¹
  5. A = 1.50
